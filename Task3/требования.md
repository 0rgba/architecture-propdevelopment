# Требования безопасности
* При передаче данных используется шифрование TLS/SSL
* Чувтвительные данные в СУБД хранятся в зашифрованном виде, происходит ротация ключей
* Должен вестись журнал аудита

# Протоколы аутентификации и авторизации
* keycloack + JWT для межсервисного взаимодействия

# Взаимодействие между системами предприятия и внешней платформой
* client-mart-app взаимодействует с государственными регистрационными органами
* tenant-core-app взаимодействует с платёжными системами и поставщиками ресурсов ЖКХ
